# Domain Docs

This is a single-context repository.

## Before exploring

- Read `GLOSSARY.md` at the repository root when it exists.
- Read relevant architecture decision records under `docs/adr/` when they exist.
- If either is absent, proceed without treating the absence as a problem.

## Layout

```text
/
├── GLOSSARY.md
├── docs/adr/
└── src/
```

Use the glossary vocabulary in issue titles, proposals, tests, and implementation notes. Surface conflicts with existing ADRs instead of silently overriding them.
