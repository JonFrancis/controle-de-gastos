# Exportação e backup

O aplicativo oferecerá exportação por período ou histórico completo em CSVs separados, Excel consolidado, Markdown e prompt para análise externa. O aplicativo não enviará dados a serviços de IA. Mensagens de cobrança e modelos de prompt poderão ser revisados antes do uso. Backups terão acionamento manual e restauração manual, com exportação automática opcional.

## Consequências

- Nenhuma cobrança será enviada automaticamente.
- O usuário terá um caminho de recuperação independente do banco local.
- Arquivos de backup não serão versionados no repositório público.
