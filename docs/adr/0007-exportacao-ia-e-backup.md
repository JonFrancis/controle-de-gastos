# Exportação, análise por IA e backup

O aplicativo oferecerá exportação por período ou histórico completo em CSVs separados, Excel consolidado, Markdown e prompt para IA. A integração prioritária será com a OpenAI por chamada explícita do usuário; mensagens de cobrança e modelos de prompt poderão ser revisados antes do uso. Backups terão acionamento manual e restauração manual, com exportação automática opcional.

## Consequências

- A análise continuará disponível mesmo sem API de IA.
- Nenhuma cobrança será enviada automaticamente.
- O usuário terá um caminho de recuperação independente do banco local.
- Chaves de API e arquivos de backup não serão versionados no repositório público.
